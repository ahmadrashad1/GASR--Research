01

Where it sits

Modules 1–3 reconstruct the surgical scene in 4D and export a per-frame trajectory of Gaussian centres. Module 4 turns that trajectory into supervision without labels: 512 anchor Gaussians per video tracked by identity, sliding context windows of W = 4 frames, and targets at three horizons k ∈ {1,2,3}.

Module 5 is the generative core. It learns the conditional distribution p(ΔG | past geometry, horizon) — how the tissue moves next, given how it has been moving. Its output is not a picture but a sampler, which is what Module 6 then queries for actual predictions.

02

The technology, and why each piece is there

Conditional DDPM
Learns a distribution rather than a single answer — tissue deformation is genuinely uncertain, and the project needs multiple plausible futures, not one.
v-prediction
Predicts the diffusion velocity instead of the noise. Far better conditioned at the tiny displacement magnitudes here (~0.004 normalised units).
Cosine schedule, T = 500
Spends more steps at high signal-to-noise, where small displacements actually live.
Min-SNR-γ, γ = 5
Stops easy low-noise timesteps from dominating the loss.
Residual target
The model predicts ΔG = Gt+k − Gt, never absolute position. See §3.
GeomMLP encoders
A shared 4-layer pointwise encoder lifts each of the 512 anchors to a 512-d latent — one network, applied per point.
Temporal transformer
Self-attention across the W = 4 frame axis, points folded into the batch, with last-token pooling: the most recent frame is the most predictive one.
Horizon embedding
Tells the network how far ahead it is being asked to predict. The single most consequential fix in the module — see §3.
Dual cross-attention
Context and noisy target exchange information in both directions over the point axis, so geometry informs the denoiser rather than only conditioning it.
EMA, 0.9999
Averages out gradient noise; the EMA weights are the inference model throughout the project.
DDIM sampling
η = 0 gives a deterministic prediction for scoring; η > 0 gives the multi-hypothesis fan-out Module 6 needs.
T4-fitting details
Mixed-precision fp16, gradient accumulation (micro-batch 16 × 2 ≡ batch 32), 3 transformer layers instead of 6 — all to fit a full run inside one Colab session.
03

Problems encountered, and what fixed them

Problem

Generating 512 absolute 3D coordinates from pure noise was intractable on this much data — CD = 2.3 against a naive baseline of 0.0005.

Fix

Predict displacement residuals instead. The model only has to produce small motion vectors, which is well within reach at this dataset size.

Problem

Those residuals were then too small. At ~0.004 normalised units the signal was drowned by unit-scale diffusion noise.

Fix

Rescale by DATA_SCALE = 1/std(Δ) so the diffusion process sees a near-unit-variance target. Inverted before every metric, so evaluation stays in physical units.

Problem

The raw trajectory was dominated by reconstruction noise: consecutive displacements had almost no momentum (r = 0.077), and constant-velocity extrapolation lost to a do-nothing baseline by 27–58%.

Fix

Adaptive per-video Savitzky–Golay smoothing, with each video choosing its own window. Autocorrelation rose to 0.89 and constant velocity went to beating naive by 30–57% — proving a learnable signal existed and was simply buried.

Problem

High-motion videos dominated the training signal; the model fit them and ignored the rest.

Fix

Per-video displacement equalisation in Module 4 — each video's target delta scaled to a common reference before training.

The one that mattered most

Problem

Module 4's multi-step augmentation puts the same context window in the dataset three times with three different targets, 1, 2 and 3 frames ahead. Module 5 was never told which. The objective was therefore a mixture over an unobservable variable, and no amount of training could resolve it — a constant-velocity predictor, last + v·k, was not even representable without k.

Fix

A horizon embedding injected into both the context and target branches, making the objective well-posed. This also explained an earlier plateau: training had stopped at epoch 460/1000 on what looked like convergence but was the ceiling of a broken problem statement, so early stopping was disabled.

Problem

Several results were measurement artefacts rather than model behaviour: diagnostic subsets took the first N windows, which all came from one video (~0.005 CD against a true ~0.019); scoring a single random DDIM draw charged the model a ~√2 error penalty; and resuming a checkpoint after Module 4 was re-run carried stale early-stopping state onto new data.

Fix

Strided subsets that span every video; N-sample ensemble averaging, since Chamfer Distance is minimised by the conditional mean and not by a draw from it; and a dataset fingerprint plus an LR-horizon guard stored in the checkpoint, so an invalid resume refuses rather than corrupting a run.

04

Where it currently stands

Module 5 does not yet beat the naive zero-motion baseline at every horizon (QT2 and QT5). The infrastructure is sound and the objective is now well-posed, but the predictive claim is not yet earned.

The honest bar is not naive anyway. Module 4 established that constant-velocity extrapolation beats naive by 30–57% on this exact data, so a two-line estimator — not a do-nothing one — is what 15.8M parameters have to justify themselves against. Every table in Modules 5 and 6 now reports all three side by side.

05

Future improvements

  • Learn the correction to constant velocity, not the raw displacement. Constant velocity already works here; the model does not. Making it the prior and having the diffusion model predict only the residual to it means the network starts from a known-good estimator and can only improve on it, rather than having to rediscover it from scratch.
  • Attack the upstream ceiling. Module 2 assumes a perfectly static camera, so real scope motion is forced into the deformation field, and monocular depth is estimated per frame with no temporal consistency term. The smoothing fix treats the symptom; a temporal depth term and camera-motion handling would treat the cause.
  • Widen the horizon coverage. The embedding table already has room for k ≤ 8 but only rows 1–3 were ever trained. Extending Module 4's PRED_STEPS costs no new data and would let direct prediction reach further without a rollout.
  • Regularisation sweep. With early stopping off, weight decay is now the main defence against late-run overfitting; raising it toward 0.05 is the first knob to try if the validation curve turns upward early.
  • More scenes. Ten videos is a small dataset for a generative model, and cross-scene generalisation is a stated validation goal.
06

How this shaped Module 6

Module 6 is inference, not training: it conditions the trained model on observed geometry and samples future tissue geometry. Nearly every design decision in it is a direct consequence of something Module 5 got wrong first.

Lesson from Module 5Consequence in Module 6
Horizons 4–8 exist in the embedding but were never trained Direct prediction is capped at k ≤ 3. Longer horizons are reached by autoregressive rollout instead, never by reading an untrained embedding row.
Biased subsets made diagnostics read 4× better than reality QT0 runs before any prediction, verifying the rebuilt trajectory is identical to what Module 5 trained on, and every origin is a genuine held-out window.
A single DDIM draw is ~√2 worse than the conditional mean N-sample ensemble averaging is the default, with the single-draw number still reported so the cost of sampling stays visible.
Naive is a weak bar; constant velocity is the real one Both baselines appear at every horizon on identical windows, and the verdict is stated against each.
A model can score well by collapsing toward "nothing moves" A smoothness test compares predicted motion against the real tissue's, catching both tearing and collapse — which Chamfer Distance alone cannot distinguish.
Diversity is not the same as confidence The 5-hypothesis fan-out is calibration-checked: if the spread does not track the error, it is reported as diversity and explicitly not as a confidence signal.
